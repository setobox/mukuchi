折叠块适合放补充说明、较长的代码或可选阅读内容。标题始终可见，点击整行展开；每个折叠块分别记录自己的状态。

## 默认收起

```md
::collapse{title="展开说明"}

这里可以继续写 **Markdown**、列表和链接。

::
```

::collapse{title="展开说明"}

这里可以继续写 **Markdown**、列表和[链接](/about)。

- 适合放不影响主线阅读的补充信息。
- 收起后，内部链接不会进入 Tab 焦点顺序。

### 折叠里的标题

点击目录中的这个标题，或[通过锚点访问本节](#折叠里的标题)，都会先展开所属折叠块再定位。直接打开带锚点的文章地址也适用。

::

## 初始展开

`:open="true"` 表示首次显示时展开，之后仍可以自由收起。省略 `open` 或填写 `:open="false"` 都会初始收起。

```md
::collapse{title="使用前请阅读" :open="true"}

这段内容在首次显示时就是展开的。

::
```

::collapse{title="使用前请阅读" :open="true"}

这段内容在首次显示时就是展开的。用 Tab 聚焦标题，按 Enter 或 Space 切换状态。

> 折叠不会删除正文，也不会改变标题的目录层级。

::

## 代码和表格

::collapse{title="查看完整的配置示例"}

```ts
const options = {
  title: '补充说明',
  open: false,
}
```

| 属性 | 默认值 | 用途 |
| --- | --- | --- |
| `title` | 展开说明 | 触发按钮显示的文字 |
| `open` | `false` | 首次显示时是否展开 |

折叠内部沿用文章的代码、表格、图片和排版样式。窄屏下，较长的代码在代码块内横向滚动。

::

## 嵌套折叠

外层使用三个冒号，内层使用两个冒号，并各自关闭。点击[嵌套的目标](#嵌套的目标)，可以一次展开沿途的两层折叠。

```md
:::collapse{title="外层说明"}

::collapse{title="内层说明"}

这里是内层内容。

::

:::
```

:::collapse{title="外层说明"}

外层和内层独立控制。收起外层后，再次展开会保留内层的状态。

::collapse{title="内层说明"}

### 嵌套的目标

这段内容位于两层折叠之内。通过目录或正文链接访问时，两层都会展开；其他折叠块的状态保持不变。

::

:::
