Markdown 使用少量标记描述文章结构。这篇教程逐项演示常用语法，每个示例都可以复制到文章中使用。

本文示例适用于本站的 Nuxt Content 环境。文章文件放在 `content/posts/`，标题、描述和日期的完整配置见[文章 Meta 示例](/posts/1.markdown/_getting-started)。

## 段落与换行

段落之间留一个空行。同一段内只按一次回车，通常仍会连成一段；需要明确换行时，可以在行末加反斜杠。

**源码**

```md
这是第一段，用于介绍文章内容。

这是第二段。
源文件中的这次回车不会创建新段落。

这是需要换行的第一行。\
这是同一段中的第二行。
```

**效果**

这是第一段，用于介绍文章内容。

这是第二段。
源文件中的这次回车不会创建新段落。

这是需要换行的第一行。\
这是同一段中的第二行。

行末保留两个空格也可以产生换行，但空格不容易辨认，编辑器还可能自动删除它们。

## 标题与目录

在行首使用一至六个 `#`，后面加空格。本站已用文章 Meta 中的 `title` 显示一级标题，正文从 `##` 开始即可。

**源码**

```md
# 文章标题

## 安装说明

### 环境要求

#### 版本检查

##### 输出说明

###### 补充信息
```

下面用三级至六级标题展示层级效果：

### 环境要求

这一层用于展开章节内的主要话题。

#### 版本检查

这一层用于说明具体步骤。

##### 输出说明

较深的层级适合补充步骤细节。

###### 补充信息

六级标题是 Markdown 支持的最深层级。通常二级和三级标题就足以组织一篇教程。

本站会从正文的二级至六级标题生成目录，不需要手写目录列表。点击目录可以跳转到相应章节；同名标题会获得不同的锚点。

## 引用

在每行前添加 `>` 表示引用。引用内可以继续使用强调、列表和嵌套引用。

**源码**

```md
> 发布前请核对文中的版本和链接。
>
> - 命令应与当前项目一致。
> - 图片应包含替代文本。
>
> > 如果引用了外部资料，请注明来源。
```

**效果**

> 发布前请核对文中的版本和链接。
>
> - 命令应与当前项目一致。
> - 图片应包含替代文本。
>
> > 如果引用了外部资料，请注明来源。

这里显示的是普通引用。带类型、图标和不同主题的提醒框属于[后续扩展](/posts/1.markdown/03.markdown-extended)。

## 列表

### 无序列表与嵌套列表

使用 `-` 表示并列条目，缩进可以建立子列表。

**源码**

```md
- 文章内容
  - 标题与段落
  - 图片与链接
- 发布信息
  - 日期
  - 标签与专栏
```

**效果**

- 文章内容
  - 标题与段落
  - 图片与链接
- 发布信息
  - 日期
  - 标签与专栏

### 有序列表

使用数字、英文句点和空格表示步骤。

**源码**

```md
1. 在 content/posts 中创建文件。
2. 填写文章 Meta。
3. 编写正文并检查预览。
```

**效果**

1. 在 content/posts 中创建文件。
2. 填写文章 Meta。
3. 编写正文并检查预览。

### 任务列表

`- [ ]` 表示未完成，`- [x]` 表示已完成。任务列表属于 GFM 扩展，当前内容解析器已支持。

**源码**

```md
- [x] 填写标题和描述
- [x] 检查文章链接
- [ ] 补充更多示例
```

**效果**

- [x] 填写标题和描述
- [x] 检查文章链接
- [ ] 补充更多示例

这些复选框展示文档中的状态，读者不能通过点击修改文章文件。

## 强调与行内代码

**源码**

```md
使用 **粗体** 标记重点，使用 _斜体_ 表示强调。
也可以组合为 _**粗斜体**_，用 ~~删除线~~ 标记已经弃用的内容。

文件名是 `example.md`，标题字段是 `title`。
如果代码本身包含反引号，可以写成 ``使用 `code` 标记行内代码``。
```

**效果**

使用 **粗体** 标记重点，使用 _斜体_ 表示强调。
也可以组合为 _**粗斜体**_，用 ~~删除线~~ 标记已经弃用的内容。

文件名是 `example.md`，标题字段是 `title`。
如果代码本身包含反引号，可以写成 ``使用 `code` 标记行内代码``。

删除线同样属于当前已启用的 GFM 扩展。

## 链接

### 普通链接

方括号内填写可读的链接文字，圆括号内填写地址。站内链接从 `/` 开始。

**源码**

```md
[文章 Meta 示例](/posts/1.markdown/_getting-started)

[Nuxt Content 文档](https://content.nuxt.com)
```

**效果**

[文章 Meta 示例](/posts/1.markdown/_getting-started)

[Nuxt Content 文档](https://content.nuxt.com)

### 引用式链接

一篇文章多次引用同一地址时，可以把地址集中写在文末。

**源码**

```md
继续阅读 [MDC 教程][mdc-guide]，了解组件语法。

[mdc-guide]: /posts/1.markdown/02.mdc-tutorial
```

**效果**

继续阅读 [MDC 教程][mdc-guide]，了解组件语法。

[mdc-guide]: /posts/1.markdown/02.mdc-tutorial

### 自动链接

将完整地址放在尖括号中，可以直接生成链接。

```md
<https://content.nuxt.com>
```

<https://content.nuxt.com>

## 图片

图片比链接多一个开头的 `!`。方括号中的文字用于说明图片内容，也供图片加载失败和屏幕阅读器使用。

将图片保存到 `apps/website/public/images/` 后，在正文中用 `/images/文件名` 引用。

**源码**

```md
![Markdown 文件经过 Nuxt Content 解析后生成文章页面](/images/content-example.svg)
```

**效果**

![Markdown 文件经过 Nuxt Content 解析后生成文章页面](/images/content-example.svg)

正文图片与 Meta 中的 `cover` 分别配置：`cover` 用于文章封面，不会代替正文图片。当前图片按普通图片显示，画廊和图片预览交互将在后续加入。

## 代码块

代码块的上下各写三个反引号，开头可以附带语言名称。当前代码着色由 Nuxt Content 的 Shiki 集成提供。

**源码**

````md
```ts
interface Article {
  title: string;
  tags: string[];
}

const article: Article = {
  title: "Markdown 教程",
  tags: ["Markdown", "写作"],
};
```
````

**效果**

```ts
interface Article {
  title: string;
  tags: string[];
}

const article: Article = {
  title: "Markdown 教程",
  tags: ["Markdown", "写作"],
};
```

常用语言标识包括 `ts`、`js`、`vue`、`html`、`css`、`json`、`yaml` 和 `bash`；纯文本可以写 `text`。

演示代码块本身时，外层使用四个反引号，内层保留三个，就能完整显示源码。文件名、行号标记和代码组写法见 [MDC 教程](/posts/1.markdown/02.mdc-tutorial)。

## 表格

表格使用 `|` 分隔列，第二行用短横线分隔表头和正文。冒号可以指定左对齐、居中或右对齐。

**源码**

```md
| 内容     |  状态  | 数量 |
| :------- | :----: | ---: |
| 基础教程 | 已完成 |    1 |
| 组件教程 | 已完成 |    1 |
| 扩展功能 | 计划中 |    3 |
```

**效果**

| 内容     |  状态  | 数量 |
| :------- | :----: | ---: |
| 基础教程 | 已完成 |    1 |
| 组件教程 | 已完成 |    1 |
| 扩展功能 | 计划中 |    3 |

表格属于当前已启用的 GFM 扩展。单元格中可以使用链接、强调和行内代码；内容较多时，分成段落通常更容易阅读。单元格中的竖线需要写成 `\|`，避免被识别为新的列。

## 分隔线与转义

在单独一行写 `---` 可以分隔正文内容，前后各留一个空行，避免与标题或文章开头的 YAML 混淆。

**源码**

```md
上一部分内容。

---

下一部分内容。
```

**效果**

上一部分内容。

---

下一部分内容。

如果需要原样显示 Markdown 标记，在符号前加反斜杠。

```md
\*这段文字保留星号\*

\# 这行不会变成标题
```

\*这段文字保留星号\*

\# 这行不会变成标题
