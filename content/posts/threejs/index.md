## 简介

Three.js 是目前 Web 端最主流的 3D 图形库之一，它对 WebGL / WebGPU 等底层图形 API 进行了封装，让开发者可以通过 JS / TS 构建 3D 场景、动画、游戏、数据可视化、产品展示以及各种 Web 交互体验。

## Three.js 官方资源

- [Three.js 官网](https://threejs.org/)

- [Three.js Examples](https://threejs.org/examples/): Three.js 官方示例。

- [Three.js Docs](https://threejs.org/docs/index.html#manual/en/introduction/Creating-a-scene): Three.js API 文档。

- [Three.js Manual](https://threejs.org/manual/): 官方教程，适合系统理解 Three.js。

- [Three.js Editor](https://threejs.org/editor/): 官方在线场景编辑器。

- [Three.js GitHub](https://github.com/mrdoob/three.js): Three.js 仓库。

## 基础使用

### 在 Vue3 中使用 Three.js

- [TresJS](https://tresjs.org/): Vue3 + Three.js 封装库，提供了 Vue3 组件化的方式使用 Three.js。

### 在 React 中使用 Three.js

- [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)

### 动画

- [GSAP](https://greensock.com/gsap/): GSAP 是一个高性能的动画库，支持 JavaScript 和 TypeScript，可以与 Three.js 配合使用，实现复杂的动画效果。

### 建模

- [Blender](https://www.blender.org/): 免费开源的 3D 建模软件，支持建模、动画、渲染、视频剪辑等功能，专题可见 [Blender 专题](/posts/blender)。

## Three.js Journey（学习之旅）

- [Three.js Journey](https://threejs-journey.com/)

非常系统的 Three.js 教程之一，也是目前我学习 Three.js 的主要资源。

从基础的几何体、材质、光照、动画、粒子系统，到后处理、物理、着色器、性能优化，再到 React Three Fiber 实战，涵盖了 Three.js 的方方面面，适合从入门一直学习到高级 WebGL / Three.js 开发。

### 书籍

- [The Book of Shaders](https://thebookofshaders.com/): 进阶技术，每章都会有可运行的例子。
